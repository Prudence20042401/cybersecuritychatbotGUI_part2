PROJECT DESCRIPTION
This application is a Cybersecurity Awareness Chatbot developed using C# and WPF in Visual Studio. The chatbot helps users learn about cybersecurity topics such as passwords, phishing and safe browsing.

FEATURES
- GUI chatbot
- ASCII art display
- Voice greeting
- Sentiment detection
- Memory and recall
- Conversation history
- Random responses
- Keyword recognition
- Exit command
- Activity log

HOW TO RUN THE PROGRAM
1. Open the solution file in Visual Studio.
2. Run the application.
3. Enter your name.
4. Enter how you are feeling.
5. Ask cybersecurity questions.
6. Type 'history' to view previous conversations.
7. Type 'exit' to close the chatbot.

TOOLS USED
- C#
- WPF
- Visual Studio
